## Repo notes

- Run: `uv run --python 3.12 --with-requirements requirements.txt python scripts/evaluate.py`
  (then `diagnose_artifacts.py`, `export_demo.py`, `make_figures.py`; see "Running it" in
  `README.md`). Set `SHOT_LOGS` if the CSV is not at `data/shot_logs.csv`.
- Tests: none. Before a commit, run `python3.12 -m compileall -q nbashots scripts` as the floor,
  plus `ruff check . && ruff format --check .` and `python3 rules_check.py .`.
- Data: `data/shot_logs.csv` is the Kaggle shot-log dataset with an unknown licence. It is
  gitignored and is never committed or redistributed, nor is any row-level derivative; only
  aggregates in `results/` are published. `models/` is gitignored.
- `results/*.json` are the recorded outputs of pre-registered runs; `figures/` is generated by
  `scripts/make_figures.py`; the notebook is the course submission. None of these are edited for
  style. The README's v2/v3 sections are the registered protocol text; keep every number as it is.
